## Project Overview

This repository contains my individual submission for Project 1, analyzing the 2020 Health Information National Trends Survey (HINTS) dataset using R and RStudio.

The project includes data management, descriptive statistical analysis, comparisons by smoking status, data visualization, and an R Markdown report.

## Dataset

The dataset contains 2,402 observations and 17 variables.

The analysis focuses on the following variables:

- Age
- Average Drinks Per Week
- Weekly Minutes of Moderate Exercise
- Body Mass Index (BMI)
- Quality of Care
- Birth Gender
- Smoking Status
- Race and Ethnicity

## Project Files

- `data/HINTSData_2020_clean.csv` - Dataset used for the analysis.
- `scripts/` - R scripts used for the project.
- `main_analysis.Rmd` - R Markdown source document containing the analysis.
- `output/main_analysis.html` - Generated HTML report with statistical results, graphs, and interpretations.

## Analysis and Visualizations

The project includes:

- Data import and exploration
- Descriptive statistics for quantitative variables
- Statistical comparisons grouped by smoking status
- Bar charts for Quality of Care and Race/Ethnicity
- Histograms for Age and BMI
- Custom R functions for generating visualizations
- Written interpretations of the results
